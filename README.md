# Diagnósticos Pine

Diagnósticos enviados para prospects, publicados em https://diagnostico.pine.marketing/[cliente]/

Este repositório é **público**. Só entra aqui o HTML final que já seria enviado ao prospect. Nada de dados internos, propostas, valores ou contatos.

O arquivo de trabalho fica no workspace privado (`ccos-ratos/briefings/[cliente]/`). Aqui fica só a cópia publicada, em `[cliente]/index.html`.

## Validade

Cada diagnóstico sai do ar sozinho depois de 90 dias (a data fica no próprio HTML e no rodapé da página). É um bloqueio visual: o arquivo continua aqui até ser apagado. Depois da data, remover a pasta do cliente.

Os HTMLs são gerados por `ccos-ratos/Pine/prospeccao/cartas/gerar-digital.js`.
